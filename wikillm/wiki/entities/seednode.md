# SeedNode

## Description

SeedNode designates a bootstrap peer used to initialise and assemble a peer-to-peer development network. It serves as the starting peer that other nodes connect to in order to bring up a local dev network. This page characterises the SeedNode role within the ProjectF dev network context (sources: [[sources/auto-watch-test_65d124|auto-watch-test]]).
